Everything LINE, from one place

Stop juggling channel tokens, webhook URLs and group IDs. LINE Manager handles them and gives your code one simple interface.

🤖

Many bots, one login

Sign in once with LIFF and manage every Messaging API channel from your phone. Webhooks are set up for you.

💬

Rooms discover themselves

Users, groups and multi-person chats show up from signed webhooks. Send /hi to register one and /id to get its ID.

📨

Text and Flex sender

Compose with a LINE-style preview, set a sender name and avatar, and send to up to 20 rooms at once.

🔑

Scoped API keys

Hashed, shown once, and limited to the registered chats of one bot. Your apps never see a LINE token.

🔀

Webhook forwarding

Fan events out to your HTTPS endpoints with signing secrets, retries, a circuit breaker and delivery history.

🛡️

Secure by default

HMAC checks, idempotent redelivery, SSRF protection and AES-256-GCM encrypted credentials. Data stays on your server.

Deploy in 5 minutes

You need Docker and a public HTTPS domain. The bundled Caddy profile gets the certificate for you.

Create the LINE side

  1. Create a LINE Login channel
  2. Add a LIFF app with endpoint https://YOUR_DOMAIN/liff/
  3. Copy the LIFF ID

Run one command

Download the compose file, fill in three values in .env, then start it. SQLite and HTTPS are included.

Add your first bot

Open the LIFF URL in LINE, tap Add bot and paste its token and secret. Webhooks and chat discovery start right away.

curl -O https://raw.githubusercontent.com/dvgamerr-app/notice-manager/main/docker-compose.yml
curl -o .env https://raw.githubusercontent.com/dvgamerr-app/notice-manager/main/.env.example

# edit .env: LIFF_ID, PUBLIC_BASE_URL, DOMAIN, CREDENTIAL_ENCRYPTION_KEY
docker compose --profile https up -d

Send from anywhere

Scripts, CI, cron jobs and servers push to LINE with one authenticated request. Rate limits are shared across instances and reported in standard headers.
